# 数据可视化平台 · 答辩演讲稿

> 面向对象：懂一点、但不深入的老师（会盯着"功能"和"你到底做没做出来"问）。
> 使用方式：**第一部分**照着念开场 → **第二部分**一边点一边讲（演示手顺）→ **第三部分**是被问到的答法（重点背熟加粗的"一句话版"）→ **第四部分**是救场。
> 全程用的数字都是**系统真实跑出来的**（480 行、总额 37.05 万…），老师当场点也经得起查。

---

## 一、开场白（30 秒，别讲技术名词）

"各位老师，我做的是一个**给不懂代码的业务老师用的数据看板工具**。

它的价值就一句话：**把一份乱七八糟的 Excel，在 1 分钟之内，变成一块能投屏、能分享、能打印的可视化大屏。**

过去要做这么一块看板，要么在 Excel 里手动做图、对齐、配色，做个把小时；要么学 Tableau、Python。我这个系统把这些都自动化了——**上传、清洗、出图、排版、分享，五步全在一个网页里点完，而且每一步我都能当场演示。**"

（说完这句，**直接进演示**。开场不要展开技术，老师一觉得"听不懂"就开始找茬，先让他看见东西。）

## 二、一分钟演示手顺（边点边说，括号里是你要讲的话）

> 建议提前登录好、切到深色皮肤，把浏览器停在工作台。深色在投影上更好看。

| # | 你做什么 | 你说什么（关键句） |
|---|---|---|
| 1 | 点「**⚡一键体验真实流程**」 | "先给各位看最终效果——**这一键，不是放个做好的动画，是系统现场跑完整条真实流程**：读 480 行销售数据 → 自动清洗 → 聚合出 4 张图 → 拼成一块大屏，全部真实写进了数据库。大概几秒。" |
| 2 | 等自动弹出大屏放映 | "看，**品类销售额环形图**——数码家电第一，11.8 万；**省份 TOP 横向排行**——广东领跑；**月度趋势折线**——11 月最旺；**品类订单量柱状图**。这些数字都是刚才那 480 行真数据算出来的。" |
| 3 | 点饼图任意一块 | "**大屏是会联动的**：我点饼图里的'美妆个护'，下面所有图表里凡是跟'美妆个护'有关的，一起高亮、其他变暗。这叫聚焦联动，汇报的时候领导说'你讲讲美妆'，我点一下，全场目光就集中过去。" |

| 5 | 关放映，点大屏卡片「🔗分享」，复制链接 | "不想装软件、不想开数据库的领导，**发个链接就能看**。我把这个链接复制到无痕窗口——" |
| 6 | 无痕窗口粘贴打开 | "**没有登录、没有账号，直接就是这块大屏，一样能联动、能导出**。不想让他看了，回来点'关闭分享'，这个链接立刻失效。" |
| 7 | 回到工作台，点「**上传表格**」 | "刚才是一键看效果。现在看**真实业务**——我自己上传一份表。" 选内置样本里的「**脏数据**」那个文件 |
| 8 | 展示清洗审计徽章 | "这份表是**故意做脏的**：有合并单元格、有'合计'汇总行、有空行。系统**自动**识别并处理了，而且每一步都写在这排徽章上——'向下填充了多少格、剔除了几行合计、识别出几个数值列'，**不是黑箱，用户看得见它做了什么**。" |
| 9 | 走完上传→选字段→出图 | "选好'看什么维度、看什么指标'，图就出来了，字段选错它还会拦住提醒。" |

**收尾一句**："整条链路——**上传清洗、聚合出图、拼大屏、联动、导出、分享、清理——各位看到的每一个按钮，背后都是真实入库、真实计算的，不是贴图，也不是提前摆好的动画。**"

> 演示翻车怎么办：万一网络慢，你就说"这个环境现在连的是学校数据库，稍等一下下"，同时翻到**第三部分**随便讲一个 Q&A 垫时间；实在打不开，退到**登录页的'离线示例大屏'**（那个不依赖网络，是内置数据），先讲界面。

## 三、刁钻问题预演答法（**这一节最重要，务必背熟每段加粗的"一句话版"**）

### 类别 A：价值 / 是不是重复造轮子

**Q：这不就是 Excel 做图吗？Excel 也能做，我用它干嘛？**
> **一句话版：Excel 要您自己排、自己对齐、自己配色、自己做图，一份看板少说一小时；我把这五步压成"上传点一下"，而且能生成一个不用装任何软件的网页链接发给别人看。**
> 展开：Excel 是**个人分析工具**，我这个是**对外交付/汇报工具**——定位不同。Excel 不会自动清洗脏数据、不会给你一个免登录的分享链接、不能一键导出高清大屏、也不能点一下就联动。这些是它做不到、或者做起来很笨的部分。

**Q：Tableau、帆软都做了好多年了，你这个有什么意义？**
> **一句话版：那些是**商业成品**，强在功能全，但贵、重、要培训；我这个是**轻量课设版**，专攻"1 分钟上手"这一个场景，砍掉一切用不上的，反而对普通老师更友好。**
> 展开（诚实）：我不跟它们比功能数量，比的是**上手速度**和**部署成本**。Tableau 要装客户端、要授权；我这是个网页，浏览器打开就能用，后端连学校现成的 SQL Server 就行。

### 类别 B：数据安全 / 分享（老师最爱问，且多半自己没想清楚）

**Q：分享链接给了外面人，别人是不是能看到我全部数据、甚至我的账号？**
> **一句话版：不会。分享链接只开放"这一块的当前画面"这一件事，是只读的；里面不含我的账号、不含其他数据集，而且我随时能一键让这个链接失效。**
> 展开：技术上我做了三层——① 链接里是一个随机 token，猜不出来；② 后端只认"这个 token 且我确实点了公开"的那一块，别的都不给；③ 返回给访客的数据里**没有任何用户身份字段**（我写了自动化测试专门验证不泄露）。老师如果担心，我当场点"关闭分享"，链接立刻 404。

**Q：那我数据存你服务器上，安全吗？别人登录能看到我的吗？**
> **一句话版：账号是隔离的，我专门写了一套 41 项的"越权测试"，就是拿两个账号互相去偷对方的数据、改对方的数据、删对方的数据，全部被系统拦住才算通过。**
> 展开：密码在库里是加密存的（scrypt），不是明文。这一步不是嘴上说安全，是**测试盯着的**——将来谁写的代码不小心能让 A 看到 B 的数据，测试当场变红。（如果被追问 token 机制，就说："登录令牌是服务器签发的、带签名和有效期，伪造和篡改都会失效，这个我也测了。"）

**Q：链接安全归安全，但万一链接被转发出去，不是人人都能看了？**
> **一句话版：这正是"公开分享"的定义——您主动选择公开这一块，拿到链接的人就能看；不想让人看，点关闭就行，关了就失效。要不要"再设个密码"是可以加的功能，但我这一版按'链接即授权'的通用做法，没做二级口令，这一点我在文档里如实写明了。**
> 关键点：**不要吹"绝对安全"**，如实说边界，老师反而信你。

### 类别 C：数据真实性 / 实时性（最容易翻车的问题）

**Q：这是不是提前做好的假数据？数字是死的吧？**
> **一句话版：不是动画。我点'一键体验'时，是后端真的把那 480 行读进来、现场清洗、现场聚合、现场写进数据库、再渲染出来的——数字、行数、图表全部是算出来的，您现在让我重新上传一份改了数字的表，图就会跟着变。**
> 展开（杀手锏）："我可以当场把数据集的行数念给您听——**480 行**，总额 **37.05 万**，这是我拿计算器一笔一笔也能加出来的数，系统聚合结果和它对得上，测试里就是这么卡的：对不上就报错。"

**Q：那原始 Excel 改了，大屏数字会自动更新吗？**
> **一句话版：不会自动跳，需要您改完重新保存一次图表，它才重算。这是我特意的设计，叫'快照'。**
> 展开（这题答好加分）："这是**一个 deliberate 的设计选择，不是 bug**。图、大屏、分享、导出，存的都是'您点保存那一刻'的结果快照。为什么不自动实时刷新？因为实时刷新意味着每次打开都要回数据库重算、还要监听文件变化，那是另一套更重的机制（数据仓库/BI 才需要）。课设场景——比如月底做一次汇报——快照反而稳定、可追溯、分享出去不会变来变去。**如果您需要'数据变了我再点一下更新'，我这条路是通的，重新跑一遍聚合就行。**"（把"限制"讲成"权衡"，显示你真想过。）

**Q：最多能导多少数据？我几万行的表能传吗？**
> **一句话版：这一版单表上限是 5000 行、50 列、5MB，超出会明确提示而不是卡死。几万行不是这个工具的目标场景。**
> 展开（诚实）："我特意设了护栏，**宁可拒绝也不静默丢数据**。要处理几万、几十万行，那是大数据平台或者数据库直连 BI 的活，硬塞进一个课设网页只会让它又慢又不稳。我选的是'把 5000 行以内的小型业务表做到丝滑'这个范围。"

### 类别 D：健壮性 / 断网 / 出错

**Q：现场要是断网了、或者服务器挂了，你是不是就没得演示了？**
> **一句话版：我留了两条腿。联网时看的是真实入库的流程；万一后端连不上，登录页有个不依赖网络的'离线示例大屏'，界面和图表照样能讲。**
> 展开：而且后端连没连上，页面上有状态灯实时告诉我，不会演到一半才发现。

**Q：上传个乱码 / 传错文件，会不会直接崩？**
> **一句话版：不会。乱码文件我能自动识别编码，格式不对、超行、超列，都会给中文提示，不会白屏。**（可以现场挑"GBK 乱码"样本演示编码自愈，很直观。）

**Q：为什么你这导出没有 PDF？（或：为什么没有 XX 图？）**
> **一句话版：PDF 和更多图型是明确没做的，我在进度表里如实写的是'未做'，没有谎报。** 这一版导出是高清 PNG（可以直接贴 PPT、可以打印），PDF 本质是把 PNG 套一页，工作量小、优先级我排在了'分享链接'后面。功能我可以按需要继续加，但**我不想虚报没做的东西**。
> （被挑"功能缺失"时，**先大方承认 + 说明取舍逻辑**，比硬撑强一百倍。）

### 类别 E：技术实现（老师多半看不太懂源码，会用这类问题试探你懂不懂）

**Q：你前后端怎么分？用的什么？**
> **一句话版：浏览器里看到的页面是前端，管数据、管账号、真正做计算的是后端，中间用接口通信；后端连的是学校现成的 SQL Server 数据库。**
> 展开：**别堆名词**（Vue/FastAPI 说一遍就够）。老师若继续追，就往"分工"上带——"我特别在意的是后端算的数**可信**，所以聚合、清洗、鉴权全放后端，前端只负责显示，这样任何人改不了我算数的逻辑。"

**Q：你代码写了多少？怎么保证没 bug？**
> **一句话版：光'自动测试'我就写了一百多项，后端几十项、前端六套真浏览器端到端、还有一百多项专门查'换肤后字看不看得清'。每次改代码跑一遍，有问题当场红给我看。**
> 展开（很圈好感）："我甚至把'踩过坑的地方'都变成了自动检查。比如本地测得好、连上学校真数据库却出过 5 个 bug，我就写了体检脚本专门在真库上验，**本地全绿我不信，真库全绿才算数**——这是我这个项目最大的教训。"

**Q：这个联动是真的点了有用，还是摆设？**
> **一句话版：真的。**（当场点一次饼图，让高亮变化给他看。）"原理是这几张图共用一套维度，点一处，把同名维度在所有图里标出来。它做的是'聚焦'，不是'重新筛数据'——这点我也如实区分过。"

### 类别 F：送命题（明显想找茬 or 怀疑不是自己做的）

**Q：这到底是不是你一个人做的？（或暗示 AI 写的）**
> **一句话版：是我做的，而且我做的一个很大部分是'决策和验收'——每一步要做什么、边界划在哪、怎么证明它真的对，都是我定、我测的。我把每个功能对应的自动化测试都留着，您随便点一个我都能当场解释它测的是什么。**
> 应对：**不要慌、不要否认用工具**（现在用工具是常态，老师知道）。把重心放在"**我懂我为什么这么做、我怎么验证它是对的**"——这才是老师真正在考的。他问不出源码细节，但会问功能取舍，这部分你必须熟（就是本节）。

**Q：那你这有什么创新点？**
> **一句话版：三点。① 把'脏表变看板'这条链路做成了一个 1 分钟傻瓜式闭环；② 清洗全程留痕、用户看得见它做了什么，不是黑箱；③ 我把'可验证性'当一等公民——越权、换肤可读性、数据不静默丢失，都有自动测试盯着。功能不是最多的，但是我能证明它对。**

**Q：如果让你继续做，下一步做什么？**
> **一句话版：三个方向——数据实时同步（改完自动刷新、不用重存）、PDF/更多图型、分享再加一层访问口令。这些我都知道怎么做，只是这一版按'课设范围'主动砍掉了。** （显得你有规划、有边界意识。）

## 四、救场卡片

**A. 被问住了 / 不会答：**
> "这个点我确实没在这一版里覆盖，**我的处理原则是宁可如实说没做，也不编一个**。我可以把它记到后续改进里。目前我能告诉您的是相邻的这块我是这么做的……"（把话题引回你熟的第二部分。）

**B. 演示卡住 / 打不开：**
> ① 别慌着解释，先点"离线示例大屏"顶上；② 说一句"现场网络连的是学校服务器，稍等一下我刷新"；③ 刷新后接着第二部分往下走。你手机/本地最好**预存一张导出好的大屏 PNG**，实在不行直接展示图。

**C. 老师非要你讲代码：**
> "代码细节我可以会后单独给您看仓库和那一百多项测试。这里时间紧，我先用**功能**证明它是真的——您随便挑一个功能点，我当场演示它跑通，比对着屏幕念代码更实在。"

**D. 三句收尾（无论被问什么都用这个收）：**
> "总结三句话：**一，一条完整能跑的链路，从脏表到能分享的看板；二，我能用上百项自动化测试证明它对、安全、不丢数据；三，我很清楚它做到了哪、没做什么，虚的我没写。谢谢老师。**"
